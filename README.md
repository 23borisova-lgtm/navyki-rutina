# Рутина на автопилоте

Два навыка Claude Code, которые снимают с человека ежедневную возню:

- **Утренний агент** — каждое утро сам смотрит календарь и почту, отсеивает
  рассылки и присылает на телефон одну строку: что сегодня и что ждёт ответа.
- **Порядок в файлах** — раз в неделю разгребает Загрузки и Рабочий стол
  по структуре владелицы. Ничего не удаляет, к каждому разбору готов откат.

Оба собраны из того, что работает в бою с сентября 2026 года, и обобщены:
никаких чужих папок, имён и адресов внутри.

## Зачем именно эти два

Их видно на второй день. Утренний агент возвращает полчаса каждое утро,
порядок в файлах — возможность найти документ за два клика вместо «скачаю заново».
Результат, который чувствуется сразу, — то, из-за чего человек не бросает
после первого урока.

## Установка

```
/plugin marketplace add 23borisova-lgtm/navyki-rutina
/plugin install navyki-rutina@navyki-rutina
```

После установки навыки подхватываются сами: скажи Claude «настрой мне утренний
разбор дня» или «в Загрузках бардак, разложи файлы».

## Что нужно

| Навык | Нужно |
|---|---|
| Утренний агент | подписка Claude, коннекторы Google Календаря и Gmail, приложение на телефоне |
| Порядок в файлах | Claude Code на компьютере, Python 3, полчаса на настройку структуры |

Коннекторы подключает владелица сама: пароли вводит только она.

```
plugin/skills/
  utrenniy-agent/
    SKILL.md                     сбор профиля, текст задачи, предохранители,

  poryadok-v-faylakh/

```

## Предохранители

Это та часть, которая отличает рабочий агент от игрушки.

**Утренний агент** только читает: календарь не меняет, письма не отправляет
и не удаляет. Если источник не ответил — говорит об этом, а не придумывает данные.
Пустой день — это ответ, а не повод наскрести мусора.

**Порядок в файлах** ничего не удаляет: очевидный мусор складывается в отдельную
папку, а сносит её владелица руками. Первый запуск — всегда холостой. К каждому
разбору печатается путь к откату. Файлы свежее недели не трогаются. Папки с кодом
и активными проектами перечисляются в настройке и не разбираются.

Отдельно: раскладывать настоящие файлы по образцу структуры скрипт отказывается.
Образец — чтобы посмотреть, как это работает, а не чтобы сортировать по чужим
правилам. Нужна своя настройка.

## Откат

Каждый разбор пишет лог перемещений и рядом готовый скрипт отката. Он возвращает
каждый файл ровно туда, где тот лежал:

```
python3 '~/Documents/_логи-разбора/ОТКАТИТЬ_<дата>.py'
```

Путь печатается в конце разбора. Его стоит сохранить, пока владелица
не убедится, что всё разложено как надо.
