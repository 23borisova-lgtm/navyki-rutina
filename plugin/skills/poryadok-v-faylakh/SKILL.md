# Порядок в файлах

Загрузки устроены так, что файлы туда только падают и никогда не уходят.
За несколько лет там оседают десятки гигабайт, найти в этой куче ничего нельзя,
и нужный документ проще скачать заново — а куча растёт дальше.

Навык ставит другую логику: Загрузки и Рабочий стол — лоток для входящих,
а не склад. Раз в неделю агент разгребает их до нуля по структуре владелицы.

Дело не в красоте. Три конкретные вещи: документы перестают теряться перед
дедлайном, поиск перестаёт быть единственным способом что-то найти, и помощник
наконец может работать с файлами — «собери все договоры аренды за прошлый год»
начинает работать.

## Что нужно до начала

- Claude Code на компьютере (навык запускает скрипт на диске).
- Python 3 — на Mac он уже есть, на Windows ставится с python.org.
- Полчаса на первую настройку структуры. Дальше всё само.

## Шаг 1. Договориться о структуре

Это главный шаг, и его нельзя пропустить: без структуры раскладывать некуда.

Спроси владелицу, какие у неё есть **большие области жизни и работы**, и собери
из них папки верхнего уровня. Не предлагай готовый список первой репликой —
сначала выслушай, потом покажи вариант.

Рабочий каркас, от которого удобно отталкиваться:

| Папка | Что внутри |
|---|---|
| `00 Входящее` | всё новое и непонятное, разбирается раз в неделю, должна быть пустой |
| `01 Работа` | внутри по темам: финансы и налоги, договоры и кадры, клиенты, материалы |
| `02 Проекты` | своё обучение, курсы, то, что делается не для клиентов |
| `03 Личное` | личные документы, отдельно от рабочих |
| `04 Архив` | всё старое и неопознанное, по годам. Не удалено — убрано с глаз |
| `05 Фото и видео` | по годам |
| `09 Мусор` | кандидаты на удаление: установщики, временные файлы |

Папка `09 Мусор` — важная часть замысла. Скрипт ничего не удаляет сам,
а складывает очевидный мусор в одно место, чтобы владелица просмотрела
и снесла целиком, когда захочет.

## Шаг 2. Записать структуру в настройку

Скопируй образец и перепиши под неё:

```
mkdir -p ~/.claude/poryadok
cp assets/struktura.example.json ~/.claude/poryadok/struktura.json
```

В файле три части:

- **`ne_trogat`** — папки, которые нельзя перекладывать: системные, папки с кодом,
  активные проекты. Сюда же попадают сами папки структуры.
- **`prefiksy_struktury`** — по каким началам имени узнаются папки структуры,
  чтобы скрипт не разбирал то, что уже разобрано.
- **`pravila`** — список правил «куда, по каким словам, по каким расширениям».
  **Порядок важен: файл уходит в первое сработавшее правило.** Поэтому личные
  документы стоят первыми, а медиа по расширениям — последними, иначе картинка
  договора уедет в фотографии.

Слова подбирай по её настоящим файлам, а не по общим представлениям. Открой
её Загрузки, посмотри на двадцать случайных имён и выпиши то, что повторяется.

## Шаг 3. Холостой прогон

Скрипт по умолчанию ничего не двигает — только показывает, что собирается сделать:

```
python3 scripts/razbor.py --only-inbox
```

Прочитай вывод вместе с владелицей. На этом шаге почти всегда находятся
две-три ошибки в правилах — это нормально, правила правятся и прогон повторяется.

Ключ `--only-inbox` ограничивает работу Загрузками и Рабочим столом. Без него
скрипт возьмётся и за россыпь в Документах — это стоит делать один раз,
осознанно, когда структура уже обкатана.

## Шаг 4. Разбор и откат

Когда вывод холостого прогона устраивает:

```
python3 scripts/razbor.py --only-inbox --run
```

Скрипт напечатает три строки: какую структуру взял, где лежит лог перемещений
и чем откатить. **Путь к откату надо отдать владелице — это её страховка.**
Откат возвращает каждый файл ровно туда, где он лежал.

Ничего не удаляется ни на одном шаге. Файлы свежее недели не трогаются —
с ними ещё работают.

## Шаг 5. Поставить на расписание

Создай задачу по расписанию (`/schedule` в Claude Code) на конец недели —
пятница вечером или воскресенье. Текст задачи:

```
Ты раз в неделю поддерживаешь порядок в файлах <имя>.
Правило её системы: Загрузки — лоток для входящих, а не склад.
К концу недели они должны быть пустыми.

ЧТО СДЕЛАТЬ

1. Холостой прогон, чтобы увидеть, что предстоит:
   python3 <путь к скрипту>/razbor.py --only-inbox
2. Если объектов к разбору ноль — ничего не запускай. Напиши одной строкой,
   что Загрузки чистые, и закончи.
3. Если объекты есть — запусти по-настоящему с ключом --run.
4. Посчитай, сколько файлов в «00 Входящее» и сколько в «09 Мусор».

ЧТО НАПИСАТЬ

Коротко, на русском, без эмодзи, не длиннее 8 строк:
- сколько объектов разложено и куда в основном;
- сколько накопилось в «09 Мусор» и напоминание, что эту папку
  можно просмотреть и удалить целиком;
- если в «00 Входящее» что-то лежит — сколько и что это.

Обязательно укажи путь к файлу отката, который напечатает скрипт.

ЗВОНОЧЕК

В конце вызови PushNotification со статусом proactive и одной строкой
по существу: «Разложено 34 файла, Загрузки чистые. В Мусоре 240 файлов —
можно удалять». Если разбирать было нечего — звоночек не отправляй вообще,
не дёргай её попусту.
```

## Предохранители

- **Ничего не удалять.** Скрипт только перемещает. Удаляет владелица, руками,
  просмотрев «09 Мусор».
- **Холостой прогон обязателен.** Первый запуск без `--run` — не формальность:
  именно там находятся ошибки в правилах.
- **Откат отдавать всегда.** Путь к откату в каждом отчёте, даже когда
  всё прошло гладко.
- **Свежее не трогать.** Файлы младше недели остаются на месте: человек с ними
  работает прямо сейчас.
- **Не разбирать чужое.** Папки с кодом и активными проектами — в `ne_trogat`.
  Разобранный проект перестаёт собираться, и это находят не сразу.

## Что идёт не так

| Что видно | В чём дело |
|---|---|
| Скрипт ругается «Нет файла структуры» | не скопировали образец в `~/.claude/poryadok/struktura.json` |
| Договоры уехали в фотографии | правило по расширениям стоит выше правила по словам — переставь, медиа всегда последним |
| Разложил папку с проектом, проект сломался | папки не было в `ne_trogat` — откати и добавь |
| Разбирает одно и то же каждую неделю | папки структуры не описаны в `prefiksy_struktury` |
| В «09 Мусор» уехало нужное | это и есть замысел: мусор не удаляется, забери обратно и поправь правило |

## Через месяц

Спроси владелицу, сколько раз за месяц она искала файл поиском. Если ни разу —
навык прижился. Если каждый день — структура не совпала с тем, как она думает
о своих делах, и правила надо переписать по её словам, а не по каркасу.
